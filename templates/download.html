Single zero-dependency native binary. RSA-PSS signing, PoW, E2EE, SSE streaming, and QUIC P2P run locally on your machine.

$artifacts_block

2. Verify Checksums & Official Signature

Never pipe remote scripts into a shell. Always verify both the SHA-256 digest and the RSA-PSS signature from ftx_fatextoffice (/k/ftx_fatextoffice.pem):

# 1. download archive (or fatext-linux-x64.tar.gz / fatext-linux-arm64.tar.gz / fatext-windows-x64.zip), manifests, and official key
$ curl -fLO https://fatext.com/dl/fatext-macos-arm64.tar.gz
$ curl -fLO https://fatext.com/dl/SHA256SUMS
$ curl -fLO https://fatext.com/dl/SHA256SUMS.sig
$ curl -fsSL https://fatext.com/k/ftx_fatextoffice.pem -o official.pem
# 2. verify Base64-encoded RSA-PSS signature and archive SHA-256 checksum
$ openssl base64 -d -A -in SHA256SUMS.sig -out SHA256SUMS.sig.bin
$ openssl dgst -sha256 -verify official.pem -sigopt rsa_padding_mode:pss -sigopt rsa_pss_saltlen:32 -sigopt rsa_mgf1_md:sha256 -signature SHA256SUMS.sig.bin SHA256SUMS
$ shasum -a 256 -c SHA256SUMS --ignore-missing
# 3. extract binary and check version
$ tar -xzf fatext-macos-arm64.tar.gz && ./fatext --version
# 4. later: check & self-update with automatic ftx_fatextoffice RSA-PSS + SHA-256 verification
$ fatext update --check && fatext update
