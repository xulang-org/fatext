2. Verify Pinned Official Key, Checksums & Signature

Never pipe uninspected remote scripts into a shell. Verify the pinned SPKI fingerprint (SHA256:NWAw8jK8DjgH48oD/JuX9O0E438pCC+rpEdGisgMBFk=) of ftx_fatextoffice (/k/ftx_fatextoffice.pem), then verify SHA256SUMS.sig and SHA256SUMS:

# 1. download archive (or fatext-linux-x64.tar.gz / fatext-linux-arm64.tar.gz / fatext-windows-x64.zip), manifests, and official key
$ curl -fLO https://fatext.com/dl/fatext-macos-arm64.tar.gz
$ curl -fLO https://fatext.com/dl/SHA256SUMS
$ curl -fLO https://fatext.com/dl/SHA256SUMS.sig
$ curl -fsSL https://fatext.com/k/ftx_fatextoffice.pem -o official.pem
# 2. verify pinned official SPKI fingerprint (must output NWAw8jK8DjgH48oD/JuX9O0E438pCC+rpEdGisgMBFk=)
$ openssl pkey -pubin -in official.pem -outform DER | openssl dgst -sha256 -binary | openssl base64 -A
# 3. verify Base64-encoded RSA-PSS signature and archive SHA-256 checksum
$ openssl base64 -d -A -in SHA256SUMS.sig -out SHA256SUMS.sig.bin
$ openssl dgst -sha256 -verify official.pem -sigopt rsa_padding_mode:pss -sigopt rsa_pss_saltlen:32 -sigopt rsa_mgf1_md:sha256 -signature SHA256SUMS.sig.bin SHA256SUMS
$ shasum -a 256 -c SHA256SUMS --ignore-missing
# 4. extract binary and check version
$ tar -xzf fatext-macos-arm64.tar.gz && ./fatext --version
# 5. optional inspect-first installer (enforces the same pinned official fingerprint by default)
$ curl -fsSL https://fatext.com/dl/install.sh -o install.sh && less install.sh && bash install.sh
# 6. later: self-update with automatic pinned ftx_fatextoffice RSA-PSS + SHA-256 verification
$ fatext update --check && fatext update
